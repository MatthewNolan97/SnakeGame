# SnakeGame
- Developed a classic Snake arcade game using Kotlin and JavaFX with a fully interactive GUI
- Implemented the Snake entity using a LinkedList, including movement, growth, and collision detection
- Built a 40x40 grid-based game board with dynamic food (apple) generation and scoring system
- Managed player data and top scores using serialization to files, including previous players and leaderboard
- Designed and implemented unit tests with JUnit to ensure correctness of Snake movement and game logic
- Applied OOP principles, overriding toString() and equals() methods for key entities
- Created robust game architecture following Kotlin language standards and best practices
- Included a Class Diagram to visualize the system structure and interactions
